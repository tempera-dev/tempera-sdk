Generate or repair one JSON editor value and validate its requested root and purpose without saving a workflow or executing a node.

- **Producer operationId:** `workflows.assistJson`
- **Auth:** Resource bearer — an OAuth access token or central `tp_` API key for audience `tempera-workflows`.
- **Scope:** `workflow:write`
- **Call as:** TypeScript `client.temperaWorkflows.assistJson()` · Python `client.tempera_workflows.assist_json()` · Rust `build_request("tempera_workflows", "assist_json", params)` · Go `BuildRequest("temperaWorkflows", "assistJson", params)` · C `tempera_build_request(..., "temperaWorkflows", "assistJson", ...)`
