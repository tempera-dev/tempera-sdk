# Tempera SDK (Kotlin/JVM)

The generated Tempera SDK for Kotlin: every product and every typed operation
in `surface.json`, with no hand-written per-product wrapper and no external
dependencies. It needs JDK 17 and nothing else — `java.net.http` for HTTP,
`java.security` for SHA-256 and the CSPRNG, `java.util.Base64` for base64url.

```kotlin
val auth = TemperaAuth(issuerUrl = provisionedIssuer, apiKey = provisionedApiKey)
val client = TemperaClient(auth = auth, environment = "staging")

val traces = client.palette.call("listTraces", mapOf("tenantId" to tenantId))
val useCases = client.dataEngine.call("listUseCases", mapOf("parent" to "projects/$projectId"))
client.tempo.request("/custom", method = "POST", body = temperaJsonObject("note" to "passthrough"))
```

Calls block. The package cannot depend on kotlinx-coroutines without imposing a
version constraint on every application that adopts it, so it exposes a
blocking API that composes with whatever concurrency the caller already has.

`src/main/kotlin/dev/tempera/sdk/Surface.kt` is generated by
`python3 scripts/gen-sdk-surface.py` from the repository root and must never be
hand-edited. Everything else is the hand-written runtime.

## Behaviour

- **Parameters** accept the producer's canonical wire name or its snake_case
  alias, never both; requests always emit the canonical name.
- **Base URL precedence** is an explicit `baseUrls` override, then the product's
  environment variable, then the `environment` preset.
- **Auth kinds**: `none`, `account` (the token `createHostedSession` returns),
  `product`, `oauthResource` (an operation-pinned audience), and
  `introspectionSecret`. PKCE is S256 and the audience travels as the RFC 8707
  `resource` parameter.
- **Timeout**: 30 seconds per attempt by default, configurable through
  `TemperaClientConfiguration(timeoutSeconds = ...)`.
- **Retry**: at most 3 attempts, on 408, 429, 500, 502, 503, 504 and connection
  failures, with exponential backoff from 250 ms (doubling, capped at 8 s) and
  jitter that lands each delay uniformly in the top half of the band. A
  `Retry-After` header wins over the backoff and is capped at 30 seconds. Only
  operations the surface classifies `read` or `idempotent` are retried at all;
  a passthrough request follows its HTTP method, so POST and PATCH are sent
  exactly once. Every attempt resends identical bytes, so an idempotency key is
  never re-minted.
- **Errors**: `TemperaSdkException` for usage mistakes, `TemperaApiException`
  for HTTP failures (normalized through the same `google.rpc.Status` cascade as
  the other packages, down to the `x-request-id` header fallback),
  `TemperaMcpException` for JSON-RPC errors, `TemperaTransportException` when no
  response arrived.
- **MCP**: `TemperaMcpClient` speaks the stateless `server/discover` lifecycle
  at protocol version `TemperaSurface.mcpProtocolVersion`.

## Build and test

From this directory:

```sh
gradle build     # or ./gradlew build once a wrapper is committed
gradle test
```

The build has no Gradle wrapper checked in; add one with `gradle wrapper` from a
machine that has Gradle 8.5+ installed.
